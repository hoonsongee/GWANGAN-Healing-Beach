# 광안 3D — 정식 공개 상설 야간 축제

- **항상 밤 모드**: 낮에도 야경을 유지합니다.
- **상설 공연**: 불꽃축제와 드론쇼가 계속 진행됩니다.
- **종이배 무제한**: 시간·일일 횟수 제한 없이, 메시지 최대 30글자. 같은 채널에 3초 표시됩니다.
- **테스트 버튼 제거**: 공연 미리보기·개발용 동행·종이배 테스트 메뉴 제거.
- **모바일**: 기존 터치 카메라 확대/이동 기능 유지.
- **BGM**: 상설 공연 중 재생됩니다. 모바일은 입장 후 오디오 활성화됩니다.

## 실행
```bash
npm install
npm start
```
`http://localhost:3000` 또는 Render 공개 주소로 접속하세요.

## GitHub/Render 갱신
압축을 풀어 **최상위** `server.js`, `package.json`, `render.yaml`과 **`public/` 아래** `index.html`, `game.js`, `style.css`를 기존 저장소의 동일 경로에 덮어씁니다. GitHub 커밋 후 Render 자동 배포가 끝나면 기존 공개 URL이 그대로 적용됩니다.

주의: Render 서버 인스턴스가 재시작되면 접속자 연결은 끊기며 재접속이 필요합니다.
